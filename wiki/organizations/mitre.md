# MITRE

## 定義
美國非營利組織，營運 [[concepts/cve|CVE]] 系統。[^z]

## 為什麼重要
CVE ID 是 SBOM 弱點比對的共通鍵，MITRE 是其編輯與主要 CVE Numbering Authority。[^c]

## 在 SBOM 生態中的角色
- CVE 的編輯與主要 CNA；資金來自美國 DHS 的 National Cyber Security Division。[^c]
- 2025-04 其與美國政府的合約曾面臨到期，後延長 11 個月。[^c]

## 主要產出
- [[concepts/cve]]

## 實務注意事項
> [!warning] 矛盾（輕微，名稱差異）
> 英文維基稱維護者為「Homeland Security Systems Engineering and Development Institute FFRDC」（[[sources/2026-10-01-wikipedia-cve]]）；中文維基稱「National Cybersecurity FFRDC」（[[sources/2026-10-01-wikipedia-zh-cve]]）。可能是不同時期的名稱（待驗證），暫並列。
